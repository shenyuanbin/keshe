# 桂林市次日最高气温预测（课程设计复现说明）

用 t 日及以前能够获得的信息，预测 t+1 日的日最高气温（TMAX，单位 °C）。
所有结果由 `run_all.py` 一次运行生成，缓存数据下约 18 秒（首次运行含下载约 2 分钟）。

## 1. 数据来源

| 项目 | 内容 |
| --- | --- |
| 数据源 | Open-Meteo 历史归档接口（ERA5 再分析） |
| 位置 | 桂林 25.333°N, 110.300°E（与 GHCN 站 CHM00057957 坐标一致） |
| 接口 | https://archive-api.open-meteo.com/v1/archive（免费、无需注册） |
| 字段 | `temperature_2m_max` / `temperature_2m_min` / `precipitation_sum`（°C / mm） |
| 使用区间 | **1951-01-01 ~ 运行日前一天**（当前 27 715 天，TMAX 零缺失，自动更新） |
| 下载方式 | 首次运行自动下载并缓存到 `work/raw/open-meteo_guilin_era5_daily.csv`；缓存早于昨天时自动重新下载，`--refresh` 强制刷新 |

**关于 ERA5 再分析**：ERA5 是欧洲中期天气预报中心（ECMWF）用观测资料校正气象模式得到的再分析值，
是气象研究中标准的“历史天气”数据，但不是站点温度计的直接读数。选择它的原因：
（1）覆盖 1951 年至今且逐日连续无缺失（GHCN 桂林站 2013 年后观测稀疏，2016 年仅 3 条）；
（2）数据自动更新到昨天，测试集可以覆盖到当前年份，还能演示“预测现实中的下一个未知日”。

## 2. 特征与可用时点

所有特征只使用预测时刻之前已观测到的值，或事先已知的日历信息。

| 特征 | 含义 | 可用时点 |
| --- | --- | --- |
| `lag1` | t 日最高气温 TMAX_t | t 日观测结束后 |
| `lag3` | t-2 日最高气温 | t-2 日 |
| `lag7` | t-6 日最高气温 | t-6 日 |
| `month` | 目标日所在月份 | 日历，提前已知 |
| `doy` | 目标日年内日序（1–366） | 日历，提前已知 |
| `doy_sin` / `doy_cos` | sin/cos(2π·doy/365.25)，季节项的周期编码 | 日历，提前已知 |

样本以“目标日”为索引：一行 = 用 t 日及以前的信息预测 t+1 日。目标值缺失（无观测）的日期直接剔除。

## 3. 时间顺序划分与防泄漏

- 按日期排序后连续切分 **70% / 15% / 15%**，全程不打乱：
  - 训练 1951-01-01 ~ 2004-02-11（19 400 条）
  - 验证 2004-02-12 ~ 2015-06-30（4 157 条）
  - 测试 2015-07-01 ~ 2026-11-17（4 158 条）
- 缺失值填充（中位数）和标准化（均值/方差）**只在训练段 fit**，之后固定不变：验证段和测试段都直接套用训练段的统计量。
- 超参数只在验证集上挑选；选定参数后模型在 train+val 上重拟合（预处理器仍只用训练段拟合），测试集只评估一次。
- 高/低温分段阈值取自**训练段** TMAX 的 33%/67% 分位（≤19.2°C 为低温段，≥27.2°C 为高温段），不用测试集分位数。

## 4. 模型

| 模型 | 说明 |
| --- | --- |
| `persistence` | 最低基线：直接用昨日 TMAX 作为明日预测，不训练 |
| `linear_regression` | 线性回归（scikit-learn） |
| `random_forest` | 随机森林，网格：`max_depth ∈ {None, 8, 14}` × `min_samples_leaf ∈ {1, 4}` |
| `gradient_boosting` | 梯度提升树（HistGradientBoosting），网格：`learning_rate ∈ {0.03, 0.1}` × `max_iter ∈ {200, 400}` × `max_leaf_nodes ∈ {15, 31}` |

验证集选出的参数（seed=42）：随机森林 `max_depth=8, min_samples_leaf=4`；梯度提升 `learning_rate=0.03, max_iter=400, max_leaf_nodes=15`。
调参后统一用 train+val 重拟合，再在测试集上评估一次。

## 5. 运行方法

```bash
pip install -r requirements.txt
python run_all.py              # 缓存可用则离线复现，过期自动更新到昨天
python run_all.py --refresh    # 强制重新下载原始数据
python run_all.py --seed 2024  # 更换随机种子
```

脚本按自身位置定位 `work/` 与 `outputs/`，因此在任意目录下执行都可以。
结果对随机种子不敏感（随机森林/梯度提升波动在 0.01°C 量级）。

**演示环节**：每次运行结束时，脚本会用截至数据截止日的全部历史重拟合模型，
输出对“下一个未知日”（数据截止后的第一天）的最高气温预测，并拉取 Open-Meteo 官方数值预报作对照，
保存到 `results/next_day_demo.csv`。此环节不参与测试集评分，用于展示模型的实际使用方式。

## 7. 测试集结果（seed=42，测试段 2015-07 ~ 2026-11）

| 模型 | MAE (°C) | RMSE (°C) | Bias (°C) | MAE 较持久性降低 |
| --- | ---: | ---: | ---: | ---: |
| persistence | 1.917 | 2.665 | +0.003 | — |
| linear_regression | 1.920 | 2.514 | -0.304 | -0.2% |
| random_forest | 1.893 | 2.496 | -0.304 | +1.2% |
| gradient_boosting | 1.905 | 2.495 | -0.340 | +0.6% |

分段误差（测试集）：

| 模型 | 低温段 MAE | 中温段 MAE | 高温段 MAE | 低温段 Bias | 高温段 Bias |
| --- | ---: | ---: | ---: | ---: | ---: |
| persistence | 2.672 | 2.213 | **1.191** | +0.63 | -0.38 |
| linear_regression | 2.407 | 2.214 | 1.378 | +0.91 | -0.90 |
| random_forest | **2.428** | **2.109** | 1.375 | +0.84 | -0.94 |
| gradient_boosting | 2.411 | 2.145 | 1.390 | +0.80 | -0.98 |

可以写进报告的观察：

1. **机器学习模型主要降低大误差**：MAE 上随机森林仅比持久性基线好 1.2%（线性回归甚至持平），
   但 RMSE 从 2.665 降到 2.496（约 6%），说明模型主要改善的是极端错天的误差。
2. **分段各有胜负**：低温段机器学习模型明显更好（MAE 2.41–2.43 vs 2.67）；
   高温段持久性基线反而最好（1.19 vs 1.37–1.39）。高温天温度连续性强，“照搬昨天”难被击败。
3. **回归均值效应**：模型在低温段系统性高估（Bias +0.8~+0.9°C）、高温段系统性低估（Bias -0.9~-1.0°C），
   持久性基线则几乎无偏（+0.003°C）。这是统计学习模型共有的收缩偏差，是很好的误差分析点。
4. **演示日的对照**（2026-11-18 运行）：统计模型预测 19.8–20.8°C，官方数值预报 15.7°C，当天有降雨。
   历史统计模型无法预知天气型转折（降水、寒潮），这是它与业务数值预报的本质差距。

## 8. 可调参数与实验建议

- `START_DATE`：分析起点（ERA5 可回溯到 1940 年）。
- `TRAIN_RATIO` / `VAL_RATIO`：划分比例，如改为 0.6/0.2/0.2。
- `FEATURES` + `FEATURE_DESC`：增删特征，例如加入 `lag2`、滚动 7 日均温、TMIN/降水滞后（注意同步更新时点说明）。
- `param_grids()`：扩大或缩小搜索网格；`--seed` 改随机种子。
- 想验证“打乱会高估性能”，可临时把划分改成随机切分对比——本脚本默认严格按时间切分。

## 9. 局限

- 单点、单变量（仅用最高气温滞后），没有引入气压、湿度、环流等预报因子；低温段高估、高温段低估的系统性偏差无法消除。
- 只用历史统计做回溯评估；模型无法预知天气型转折（如降温降雨事件），业务预报仍需数值天气模式。
- ERA5 为再分析值而非站点实测，绝对数值与温度计读数可能有小差异；结论反映的是 ERA5 口径下的可预测性。
